Evidence and future-work ledger

This first-draft ledger summarizes retained project records as of 2026-10-01. E-identifiers name local studies, not external publications. Raw private inputs and reasoning traces are not public artifacts. Counts below are source-recorded observations; this manuscript did not rerun the experiments. Public primary sources are linked in the relevant chapters. Mutable model cards describe source observations and require immutable revision checks before a new execution.

E01: Workflow and sparse evidence

Source record: “Jobsearch Laya System 1,” 2026-09-29, with the architecture article’s frozen-shadow analysis. Historical workflow result: 300/300 survive; option reversal and policy enrichment each changed 0/300 decisions. Separate sparse-shadow result: 18/149 label matches across twenty cards; 0/94 correct not_stated decisions. References are diagnostic, not human gold. Card-level dependence prevents interpreting 149 heads as independent observations. These results concern the tested routes, not every zero-shot model.

E02: Adapter study

Source record: “Decision-model adapter benchmark,” final result, 2026-09-30. Forty configurations × 36 authored scenarios = 1,440 decisions. No invalid responses or reported input truncation; no configuration eligible; eighteen confirmation scenarios unused. Author labels are provisional synthetic references. Representative counts preserve separate task denominators:

Laya typed, dual NLI, full 27 2 6 9 2
Nano-Jev, native grounded dual, full 16 0 3 1 0

No cross-model speed conclusion follows: OpenJev used quantization and partial CPU offload. Searching forty configurations also creates selection risk. The untouched confirmation set was correctly left unopened after rejection at the development gate.

E03: Native family comparison

Source record: “Council proxy references and System-1 evaluation,” final main report002, annotation appendix002 and supplementary report002, 2026-09-30. Fourteen lanes × 108 cards = 1,512 main records; 36 development and 72 confirmation cards per lane. Confirmation has twelve groups. Astra references: 36 valid development and 72 valid confirmation; Gemini: 35 valid development, one preserved invalid citation response, 72 valid confirmation. Confirmation status agreement is 58/72. These named report versions identify the reference snapshot; public summaries do not expose a complete reproducible judge/rubric manifest.

The separate twelve-card answer-annotation comparison includes the contradicted answer with Qwen relevance 0.99855. Perfect nDCG@3 on tiny three-passage retrieval slates is not answer correctness; token overlap already scored 0.9692. The 756 supplementary option-order calls are post-confirmation development diagnostics, not additional held-out confirmation. None of these references is human-adjudicated gold.

E04: Prompt controls

Source record: “Laya prompt interventions,” 2026-09-30. Six fictional cases, four underlying claim families, eleven conditions, two checkpoints: 132 decisions. Each checkpoint matched 4/6 baseline references, with stable errors under tested meaning-preserving changes; evidence removal and decisive edits each matched 6/6 transformed references. Only four originally resolved cases count as resolved-to-unresolved transitions. A blinded assistant review agreed with authored references; this is model-reviewed synthetic evidence, not human gold or a reliability estimate.

E05: Corpus-informed probes

Source record: “Laya training-corpus patterns and fresh prompt probes,” 2026-10-01. Public TRAIN corpus revision d0e2f0c42fef86cc15d1688d25a19f5ba7c85b18; cached base/typed model revision 55cf4c4ebb4ebe31b2550e8bdf3bd21b99753851. Exact corpus-to-training-run correspondence is unverified. Thirteen fresh base cases generated 156 main predictions; five customer messages across three tiers and two models generated thirty more. Total: 186. Independent assistant references, no training-row evaluation, no untouched confirmation, near-replicates retained as a limitation. Base invoice matching improved 2/4 to 4/4 with rewording; typed matching fell 4/4 to 2/4 with generic keys; both duplicate classifiers remained constant at 2/4.

E06: Expanded study status

Source record: “Expanded Laya prompt study,” pre-inference freeze, 2026-10-01. Prepared: 150 scenarios, ninety development and sixty confirmation, fifty per task. Four fixed conditions; maximum 720 development and 240 confirmation predictions are budgets, not completed counts. Independently reviewed labels agreed with author labels on all prepared scenarios. Ten patterns per task are uncertainty clusters, and overlap limits confirmation to fresh cases within known mechanisms. No inference results are reported at this snapshot.

E07: Spark pilot

Source record: “Spark-X2.5 on-device annotation judge,” final analysis, 2026-10-01. Official GGUF revision 9826e0be84e6e6e8b9668abc91421109a1df1e2d, Q8_0, 4,375,021,152 bytes; llama.cpp build11147. Twelve cards/six paired groups in each mode; 24 total outputs. Native thinking: one accepted, eleven completion-budget failures. Nonthinking: seven accepted, five citation-invalid. Median latency 34.31 s versus 3.85 s. Same retained Astra/Gemini proxy panel, with legacy wrapper limitations; no new human reference certification.

Eight of twelve nonthinking compliance rationales showed target confusion: five accepted, three citation-invalid. This diagnostic inspection does not admit rejected outputs into semantic metrics. Pipeline denominators remain twelve. No semantic superiority, calibrated trust, full annotation economics or 108-card job-benchmark result follows.

E08: Memory feasibility

Source record: Laya architecture article, corrected steady-state VRAM probe. Eight-row micro-batch: 8.2186 GiB peak allocated, 8.9062 GiB reserved, 10.526 GiB free at process start. Synthetic 1,024-token rows, 256-token head, accumulation four, FP32 weights/gradients/Adam state, FP16 autocast and GradScaler, encoder/head checkpointing, second update completed. Auxiliary training operations and full end-to-end variation were absent. This supports limited memory feasibility, not task-training performance.

Future work
